# Heart_Failure_30-Day_Readmission_Prediction
Heart Failure 30-Day Readmission Prediction is a machine learning project that predicts whether a heart failure patient is likely to be readmitted within 30 days. The project covers data preprocessing, feature encoding and scaling, train-test splitting, model training, hyperparameter tuning, and performance evaluation using Logistic Regression, KNN, and Decision Tree models.
